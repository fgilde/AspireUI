# Contact & support

A question about a page here, a bug, an app you would like to see in the store — write, it arrives.
Bug reports and feature requests are usually better off as a
[GitHub issue](https://github.com/fgilde/AspireUI/issues), where everyone else can find them too.

## Supporting the project

AspireUI is MIT, self-hosted and has no paid tier — nothing here is behind a wall, and nothing is
planned to be. If it saves you an afternoon now and then, this is the way to say so.

## Other ways

- **[Issues](https://github.com/fgilde/AspireUI/issues)** — bugs, and anything worth a public trail.
- **[Discussions](https://github.com/fgilde/AspireUI/discussions)** — questions and ideas.
- **[Submit an app](app-manifest.md)** — the store takes pull requests, and the manifest is one JSON file.
- **[Export & import](instance-transfer.md)** — a support bundle carries an instance's settings, targets and logs.
