# AspireUI — CasaOS app source

A one-app CasaOS store: **AspireUI**, a self-hosted app platform and visual builder for container
stacks and .NET Aspire.

Add it in CasaOS under *App Store → Add source* with this URL:

```
https://github.com/fgilde/AspireUI/releases/download/store/casaos-appstore.zip
```

The archive is rebuilt from `store/casaos/` on every push to master. Source and issues:
https://github.com/fgilde/AspireUI
